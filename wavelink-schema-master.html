Wavelink / getwaved.ai — production JSON-LD master file

This file is your working reference: each block below is a self-contained <script type="application/ld+json"> you can paste into your CMS <head> (or inject per route). Schema 5 is not JSON-LD — it is the Wikidata creation guide.

Non-negotiable before go-live: validate every block in Google Rich Results Test. Invalid structured data can reduce trust signals from search and AI surfaces.

Deployment map: 2 global blocks (Organization + LocalBusiness) + 3 page-specific AggregateRating blocks + 5 page-specific FAQ blocks = 10 JSON-LD scripts, plus the Wikidata guide.
